A fast, clean WordPress blog theme built with Tailwind CSS.

== Description ==

Blog Pro is a lightweight, fast-loading blog theme styled with Tailwind CSS.
It features a clean front page, full archive/author/category/tag templates,
comment support, and WooCommerce compatibility.

= Features =

* Tailwind CSS-based styling
* Responsive layout with mobile navigation
* Custom front page template
* Archive, category, tag, taxonomy, author and search templates
* Comment and trackback support
* Widget areas (see /widgets)
* WooCommerce template support

== Installation ==

1. In your WordPress dashboard go to Appearance -> Themes -> Add New -> Upload Theme.
2. Choose blog-pro.zip and click Install Now.
3. Click Activate.

== Frequently Asked Questions ==

= How do I customize the colors? =
Edit input.css (Tailwind source) and run the Tailwind build to regenerate assets/css/tailwind.css.
